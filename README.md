# 🏝️ Dinamik Ada (Huawei P40 Lite)

Google servisi (GMS) gerektirmez, hiçbir dış kütüphane yok — sadece saf Android API'leri.

## APK nasıl alınır (GitHub Actions)
1. GitHub'da yeni bir repo aç, bu klasörün **tüm içeriğini** yükle (`.github` klasörü dahil!).
2. Repo > **Actions** sekmesi > "APK Derle" otomatik çalışır (~3-4 dk).
3. Derleme bittikten sonra APK **GitHub Releases** bölümünde yayınlanır.
4. İstersen "Actions" çalışmasının içindeki **DinamikAda-APK** dosyasını da indirebilirsin.
5. Telefonda APK'ya dokun > kur (bilinmeyen kaynaklara izin ver).

## Kurulum sonrası
Uygulamayı aç, 1-4. adımları sırayla yap, "Adayı çalıştır" anahtarını aç.
Kamera deliğine hizalamak için yatay kaydırıcıyı sola çek.
